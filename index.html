i How it works

1
Download & extract the plugin ZIPSave it to a permanent folder, e.g. C:\Tools\PRAgingReminder\ — do not move it after install.
2
Create a PAT and a Teams webhookTwo quick steps below — takes about 3 minutes total.

4
Reminders run automatically every weekdayA Windows Scheduled Task fires Mon-Fri at 09:00. No cloud required

A Create an Azure DevOps PAT

1
Open your PAT settings Go to dev.azure.com → User Settings → Personal Access Tokens (or click your avatar top-right → Security).
2
Click “New Token” Give it a name like PR Aging Reminder, set expiry to 1 year.
3
Set scope: Code → Read only Under Scopes, select Custom defined, then tick Code → Read. No other scopes needed.
4
Click Create → Copy the token You will only see it once. Paste it in the form below.

B Create a Teams Incoming Webhook

1
Go to the channel you want alerts inThis is usually a personal or team channel (e.g. #pr-reviews or your own General).
2
Click the “⋯” (More options) next to the channel nameThen select Manage channel.
3
Scroll to “Connectors” → click EditIn the Connectors panel, search for Incoming Webhook and click Add.
4
Configure the webhookGive it a name like PR Aging Reminder, optionally upload an icon, then click Create.
5
Copy the webhook URLThe URL starts with https://microsoft.webhook.office.com/... or https://outlook.office.com/webhook/.... Copy it and paste below.
1
Go to the channel you want alerts in
2
Click “⋯” next to the channel → Connectors
3
Search “Incoming Webhook” → Configure
4
Enter a name → click Create
5
Copy the URL → click DonePaste the URL in the form below.
