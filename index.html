A Prerequisites

1
Download plugin ZIP Download PRAgingReminder.zip and extract to a permanent folder.
2
Create an Azure DevOps PAT Go to dev.azure.com → User Settings → PATs → New Token → Scope: Code > Read → Copy the token.
3
Create a Teams Incoming Webhook In your Teams channel: ··· → Connectors → Incoming Webhook → Configure → Copy URL.
Skip if using email-only notifications.
